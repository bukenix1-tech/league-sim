# 経営の中身（2026-10-31 に選んだもの）

プレイヤーは監督ではなく、**クラブの経営者（オーナー・GM）**。
試合の作戦は監督に任せ（自動）、経営者はお金・選手・施設を決める。
深さは野球ゲームのペナントくらい。項目は少なく、1 シーズンが軽く回るテンポを大事にする。

長く遊ぶ面白さ: **2 部の小さなクラブから育てて、1 部で優勝するまで**。

## 入るお金

| 項目 | 中身 | 決まり |
|---|---|---|
| 入場料 | 観客数 × 入場料。観客数は人気・順位・スタジアムの大きさで決まる | 入れる（入場料の値段は自動） |
| 放映権 | リーグから配られる。1 部と 2 部で大きく違い、順位でも少し増える | 入れる |
| スポンサー | シーズンの初めに決まる額。人気と前の年の順位で増える | 入れる |
| グッズ | 人気に比例する | 入れる |
| 選手の売却 | 移籍で出したときの移籍金 | 入れる |
| パラシュート | 降格したクラブが 2 年間、2 部で放映権を多めにもらう（本物のリーグにもある） | 入れた（段階 4 で、昇格したクラブがすぐ落ちすぎるのを防ぐため） |

## 出るお金

| 項目 | 中身 | 決まり |
|---|---|---|
| 年俸 | 選手と監督の年俸の合計。一番大きい出費 | 入れる |
| 移籍金 | 選手を取るときに払う | 入れる |
| 施設代 | 施設を大きくする費用と、毎年の維持費 | 入れる |

## 経営者が決めること

| 項目 | 中身 | 決まり |
|---|---|---|
| 年俸の予算 | 1 年に年俸へ使える上限 | 入れる |
| 選手の獲得と放出 | 夏の移籍の時期に、リストから選んで取る・売る | 入れた（段階 5）。冬の移籍は「あとで」（2026-10-31 に決めた） |
| 契約の交渉 | 選手の契約年数と年俸を決める。契約が切れると選手が出ていくこともある | 入れた（段階 5。年俸は選手の力で決まり、年数を選ぶ） |
| 施設への投資 | スタジアム（観客数）・練習場（選手の伸び）・育成（若手の質） | 入れた（段階 5） |
| 監督を雇う・解任する | 監督の能力と型（攻撃的・守備的・若手を育てる） | あとで（最初は監督が固定） |
| 入場料の値段 | 高いと収入が増えるが観客と人気が減る | あとで（最初は自動） |
| スタッフ（コーチ・スカウト） | 施設の中に含める | 入れない |

## 結果として変わるもの

| 項目 | 中身 | 決まり |
|---|---|---|
| 人気（ファンの数） | 勝つと増え、負けると減る。入場料・スポンサー・グッズに効く | 入れる |
| オーナーの期待 | シーズン前に目標（「降格を避けろ」「上位半分」「優勝」）が出て、終わりに評価される | 入れる |
| 別のクラブから誘われる | 成績が良いと、もっと大きいクラブから声がかかり、移ることができる | 入れた（段階 5） |
| クビ（ゲームオーバー） | 期待を下回り続ける、借金が大きすぎると終わり | あとで |

クビが無いあいだは、オーナーの期待は「評価」として出るだけにする。
ただし、借金が増えすぎないよう、年俸の予算はお金の残りで上限がかかる。

## 段階 5 で足したもの（強いクラブの固まりを崩すため）

- スター選手の年俸は強さの割に高い。海外のクラブがスター選手を引き抜く（自分のクラブにはオファーとして届く）
- 手元のお金が貯まりすぎると、オーナーが配当として持っていく
- 優勝したクラブは選手の年俸が上がる
- 年ごとの調子の波。コンピューターのクラブは、成績が悪いと監督を解任する

## 入れないもの

- 試合の作戦や先発を経営者が決めること（監督に任せる）
- 税金・ローン・株などの細かいお金の仕組み
- 実在のクラブ・選手の名前（全部架空）
