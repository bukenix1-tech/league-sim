# サッカーのリーグ運営シム（段階 1）

20 チームが 2 回ずつ当たる 38 節のリーグを、数字の計算だけで 1 シーズン回すプログラム。
画面はまだ無く、結果は文字で出る。Python 3.10 以上で動き、ほかに入れるものは無い。

## 動かし方

このフォルダで実行する。

1 シーズンを回して順位表を出す（`--seed` を同じにすると同じ結果になる）:

```bash
python run_season.py --seed 42
```

全 380 試合の結果も見たいときは `--results` を付ける。

1000 シーズン回して、本物のリーグの目安と比べる:

```bash
python simulate.py --runs 1000 --seed 1
```

試験を走らせる:

```bash
python -m unittest -v
```

## しくみ

- **日程** (`league/schedule.py`): サークル方式で前半 19 節を作り、後半 19 節はホームとアウェーを入れ替えて繰り返す。各チーム 38 試合（ホーム 19・アウェー 19）。
- **試合** (`league/match.py`): 得点の期待値を
  - ホーム = `BASE_GOALS × HOME_ADVANTAGE × ホームの攻撃 ÷ アウェーの守備`
  - アウェー = `BASE_GOALS × AWAY_FACTOR × アウェーの攻撃 ÷ ホームの守備`

  で出し、それぞれポアソン分布から点数を引く。
- **順位表** (`league/table.py`): 勝ち 3・引き分け 1。勝ち点 → 得失点差 → 総得点 の順に並べる。
- **チームのデータ** (`data/teams.json`): 名前・攻撃・守備。1.0 がリーグの平均。いまの値は全部仮で、名前も架空。
  好きなクラブ名や値に書き換えてよく、別のファイルを `--teams 別のファイル.json` で渡すこともできる（チーム数は偶数）。

## 1000 シーズンのまとめ（seed = 1）

| | 結果 | 本物の目安 |
|---|---|---|
| 優勝チームの勝ち点 | 87.1（最小 74・最大 105） | 85〜95 |
| 1 試合の平均得点 | 2.71 | 約 2.7 |
| 引き分けの割合 | 23.2% | 約 25% |
| ホームの勝ちの割合 | 44.4% | 約 45% |

引き分けが少し少ないのは、両チームの点数を別々に引くポアソン分布のよく知られた癖。
気になるなら、後で「0-0 や 1-1 を少し出やすくする」補正（Dixon-Coles）を足せる。
